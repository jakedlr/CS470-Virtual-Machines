# Systems Infrastructure Project

### This was a project/group of projects from my CS470 Unix System Administration class at SDSU taught by Instructor Peter Bartoli
### This project took up ~490GB of space which is much larger than github allowed me to upload so I put it on Google Drive
### Link: https://drive.google.com/drive/folders/16mt2IW5OZUy-b6WMWZ8_aSZC2RpUcE7K?usp=sharing

#### Project Highlights:
- Constructed and integrated a multi-VM environment across Linux, BSD, and Unix systems
- Configured core services including DNS, LDAP authentication, PKI certificate management and TLS, email (SMTP/IMAP), and NFS file sharing
- Deployed web services using Docker and nginx, and provisioned infrastructure in Proxmox Private Cloud and Microsoft Azure
- Performed system debugging, automation, and monitoring through log analysis, cron jobs, and service configuration
